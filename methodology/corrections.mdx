SunshineFM corrects errors quickly and transparently.

## What gets corrected

- Factual errors (names, dates, numbers, claims)

- Misattributions (wrong source or missing link)

- Missing context that materially changes interpretation

## How corrections work

- We update the page as soon as possible.

- We add a brief note describing what changed.

- We prefer **clarifying** over silently deleting.

## Suggested correction note format

At the bottom of the page:

**Correction (YYYY-MM-DD):** Updated [what changed] based on [transcript / source link].
