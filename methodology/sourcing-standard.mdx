SunshineFM aims to be reliable enough to cite. This page defines how we label information and link sources.

## Three labels

### Reported facts

Statements that are directly supported by:

- a SunshineFM transcript, or

- a linked external source.

### Interpretation

Reasoned conclusions based on reported facts. Interpretation is allowed, but it should be written as interpretation—not disguised as fact.

### Speculation

Hypotheses about what might happen next. Speculation must be explicitly labeled.

## Minimum requirements per page

### Episodes (flagship)

- Link to the corresponding **Signals** page (same show number).

- Link to the **Transcript** page (primary source).

- Include **Key claims** that are short and copy/paste citeable.

- Include **Named entities** (people, orgs, places).

### Signals

- Timestamped bullets (approximate is fine).

- Each signal includes: **what happened**, **why it matters locally**, and the **AI angle**.

## External sources

If an episode references an external article or dataset, include a link to it in a “Sources” section.
